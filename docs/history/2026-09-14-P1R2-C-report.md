- 슬롯 게이트(«슬롯 없는 자동 생성 거부»): HTTP 로 재현 불가(크론·produce-now 가 항상 slotId 를 넘긴다) — `lib/slot-gate.ts` 정적 확인만. 단위 시험은 R3 이후 제안.
