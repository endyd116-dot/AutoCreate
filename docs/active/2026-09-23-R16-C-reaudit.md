2. **«재서» 말한다** — 전부 `grep` + `export const config` + `public/**` 세 겹.
3. **남이 잰 숫자엔 출처** — 이 판엔 남의 숫자를 안 썼다(메인의 «20» 도 **내가 다시 세어** 확인했다).
4. 🔴 **대용물 조심** — `avatar`·`account_groups` 가 그 함정이었다. 서버만 보고 ✅ 를 매겼으면 **둘을 잘못 닫을 뻔했다.**
5. **⊘ 를 통과로 안 썼다** — 위 셋은 🟠 로 남겼다.
6. 🔴 **고치지 않았다** — `avatar` 화면은 «5분이면 될 것»처럼 보였지만 **적어만 뒀다**. 제품 나무 변경 **0**.
