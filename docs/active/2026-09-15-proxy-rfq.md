# 프록시 견적 요청서(RFQ) — 사장님이 그대로 붙여 넣는 한 장 · 2026-09-15

> 왜 이 문서인가: 공급사 **공개가는 «부터»** 다(대량·한국·sticky 조건이 붙으면 달라진다).
> 그런데 **견적 요청은 사장님 이름으로 나가는 대외 접촉**이라 우리가 대신 시작하지 않는다(AC-50).
> 그래서 **붙여 넣기만 하면 되는 글**을 만들어 둔다. 답이 오면 `docs/active/2026-09-15-proxy-cost.md` §4-2 표를 채운다.
>
> 🔴 **협상 카드는 우리 실측이다** — 우리는 «계정당 월 0.3~0.9GB»를 **재서** 안다(§4.1). 공급사 영업은 보통
> 트래픽을 모르는 고객에게 큰 GB 상품을 판다. 숫자를 먼저 말하면 그 대화가 안 열린다.

---

## 0. 먼저 — 물어보기 전에 정해야 할 것 하나

**계정을 몇 개로 시작할 것인가.** 이 숫자에 따라 단가와 협상력이 달라진다.

| 우리 상황 | 권장 질문 수량 |
|---|---|
| 지금(사장님 테스트 계정 몇 개) | **10개** 견적만 받아도 충분 |
| 첫 고객 몇 명 | 10 / 20 / 50 **셋 다** 받아 두면 나중에 다시 안 물어봐도 된다 |

> 🔴 원가표 §6.2 결론대로 **모바일 회선 자체 구축이 더 싸다**(계정당 ₩1,000~2,400 vs ₩3,400~7,000).
> 그러니 이 견적은 «**비교군**»이다 — 받아 보고 모바일 회선보다 유리하지 않으면 **안 사도 된다.**

## 1. 붙여 넣을 글 (영문 · 해외 공급사 채팅/메일용)

```
Hi,

I'm evaluating proxies for a Korean content-automation SaaS. Each end-user account
must keep a stable, dedicated exit IP. I have measured our actual usage, so I can be
specific:

  - Measured traffic: 0.3 - 0.9 GB per account per month (mostly image uploads).
  - Region required: South Korea (KR) exit IPs.
  - Type: static residential / ISP preferred. Datacenter is not usable for us.
  - Sessions: each account must keep the SAME exit IP over months, not just per session.

Could you quote and confirm the following?

 1) Do you actually have KR static residential IPs in stock right now?
    How many can you deliver at once (10 / 20 / 50)?
 2) Price per IP per month at 10, 20, and 50 IPs.
 3) Is the exit IP guaranteed to stay the same? For how long?
    What happens when an IP is retired - do I get a replacement, and at what notice?
 4) Is there any bandwidth cap per IP? What happens if it is exceeded
    (throttle / overage charge / cut off)?
 5) If you also offer rotating residential with sticky sessions:
    price per GB, maximum sticky duration, and whether the SAME IP can be pinned
    for months rather than minutes.
 6) Payment terms: monthly / prepaid, minimum commitment, refund policy.
 7) Is there a free trial or a paid test of 2-3 IPs before committing?
 8) Acceptable use: our traffic is publishing blog posts to Korean platforms
    from the account owner's own accounts. Any restriction I should know about?

Thanks,
```

## 2. 붙여 넣을 글 (한국어 · 국내 공급사/리셀러용)

```
안녕하세요. 한국 IP 프록시 견적을 문의드립니다.

저희는 콘텐츠 자동 발행 서비스를 운영하며, **계정 1개당 전용 한국 IP 1개**를 고정으로
써야 합니다. 사용량은 실제로 측정했습니다.

  · 계정당 월 트래픽: 0.3 ~ 0.9GB (대부분 이미지 업로드)
  · 필요 지역: 한국
  · 유형: 정적 주거용(ISP) 우선 · 데이터센터는 쓸 수 없습니다
  · 요구사항: 같은 계정은 **몇 달 동안 같은 출구 IP** 를 유지해야 합니다

아래를 확인 부탁드립니다.

 1) 한국 정적 주거용 IP 재고가 지금 실제로 있는지, 한 번에 몇 개까지 가능한지(10 / 20 / 50)
 2) 10개 / 20개 / 50개 기준 IP 1개당 월 단가
 3) 출구 IP 고정 보장 여부와 보장 기간 · IP 회수 시 교체 정책(사전 통지 기간)
 4) IP 당 대역 상한 유무 · 초과 시 처리(속도 제한 / 추가 과금 / 차단)
 5) 회전 주거용(GB 과금)도 있다면: 1GB 단가 · sticky 최대 유지 시간 ·
    **같은 IP 를 수개월 고정**할 수 있는지
 6) 결제 조건(월 후불 / 선불) · 최소 약정 · 환불 정책
 7) 계약 전 2~3개로 테스트할 수 있는지(무료 체험 또는 소액 유료)
 8) 이용약관상 제한 — 저희 트래픽은 «계정 주인 본인 계정으로 블로그 글 발행» 입니다

감사합니다.
```

## 3. 어디에 보낼까 — 후보 3곳 + 자체 구축

| # | 후보 | 왜 | 먼저 볼 것 |
|---|---|---|---|
| 1 | **Proxy-Cheap** | 원가표 §1 에서 한국 정적 주거용 **$2.44~2.87/IP/월** 로 가장 싸게 공개돼 있다 | 🔴 **한국 재고**가 실제로 있나(공개가는 미국 기준인 경우가 많다) |
| 2 | **PrivateProxy** | 대량 구간 $5 → **$2.50** 로 떨어진다 | 그 할인이 **몇 개부터**인지(1,000개 기준이면 우리와 무관) |
| 3 | **Oxylabs / Smartproxy 급 대형** | 재고·안정성이 낫고 sticky 보장을 문서로 준다 | 최소 약정이 큰 편 — **테스트 가능 여부**부터 |

> **4번째 선택지 = 사지 않는 것**: 원가표 §6.2 «모바일 회선 자체 구축»(알뜰폰 20GB 1회선 + 라우터).
> 계정당 **₩1,000~2,400** 으로 위 셋보다 싸고, §2.4 관리형 노트북 옆에 두면 그대로 맞는다.
> **위 견적은 이 선택지와 비교하기 위한 것**이지, 사기 위한 것이 아니다.

|---|---|---|---|---|---|---|---|---|
| Proxy-Cheap | | | | | | | | |
| PrivateProxy | | | | | | | | |
| (3번째) | | | | | | | | |
| **모바일 자체(비교군)** | 해당없음 | **₩1,000~2,400/계정** | 동일 | 동일 | 🔴 IP 가 자주 바뀐다(모바일은 그게 정상) | 20GB/회선 | 월 | — |

🔴 **고를 때 기준은 «싼 값»이 아니다.** 3번(IP 고정 보장)이 없으면 계정-IP 1:1 이 깨지고,
그러면 이 기능을 만든 이유 자체가 사라진다 — **보장 없는 싼 상품보다 보장 있는 비싼 상품이 맞다.**

## 5. 🔴 계약 전에 반드시 확인(사고 예방)

- **테스트 없이 50개를 사지 않는다.** 2~3개로 우리 러너에 물려 **실제로 한국 IP 로 나가는지**(우리 출구 IP 확인 기능이 그걸 잰다) 본 뒤에 늘린다.
- **환불 조건**을 받아 둔다 — 한국 재고가 «있다»고 했는데 막상 미국 IP 가 오는 일이 흔하다.
- 약관에 **자동화 금지** 문구가 있는지 본다(있으면 나중에 계정이 통째로 잘린다).
- 결제는 **월 단위로 시작**한다. 연 선불은 싸 보여도, IP 품질이 나쁘면 되돌릴 수 없다.
