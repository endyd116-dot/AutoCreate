# A 트리거 — 🔴 «첫 손님»이 되어 처음부터 끝까지 걸어 본다 (2026-09-19 · 사장님 지시)

## 0. 왜
라이브에 **진짜 가입한 사람이 0명**이다. 우리는 «가입·비번 찾기·정보 변경이 **코드에 있다**»까지만 안다.
🔴 **«된다»는 아무도 안 봤다.** 이번 일은 **네가 손님이 되어 직접 걸어 보는 것**이다.

## 1. 어디서 도나 — **로컬. 푸시 안 한다**
```
npx netlify dev            # 화면 + 서버가 로컬에서 같이 뜬다
```
- DB 는 **라이브 Neon** 을 그대로 쓴다(별도 DB 를 파면 품이 더 든다).
- ⇒ **네가 만드는 행은 진짜 행이다.** 아래 §2 를 반드시 지켜라.

## 2. 🔴 절대 선
- **새 테넌트·새 사람만 만든다.** 이름·메일에 `scenario-a-<날짜>` 를 넣어 **누가 봐도 시험인 줄 알게** 한다.
- 🔴 **보존 테넌트 3·13·109·116·198(+451) 은 읽지도 쓰지도 마라.**
- 🔴 **`ai_usage`(돈 쓴 기록)는 어떤 경우에도 안 지운다.**
- 🔴 **provider 실호출 금지**(글·이미지·영상 생성 = 돈). 거기 닿으면 **멈추고 «여기서 AI 가 필요하다»고 적어라** — 그 구간은 C 가 따로 돌고 있다.
- 🔴 **실결제 금지.** 요금제·충전 화면은 **보기까지**. 결제 버튼 누르지 마라.
- 🔴 **실발행 금지.** 바깥 채널에 아무것도 올리지 마라.
- **push 금지.** commit 만.

## 3. 걸어야 할 길 (손님 눈으로)
한 단계씩 **실제로 화면을 눌러서** 간다. 코드를 읽어서 «되겠지»로 넘어가지 마라.

| # | 단계 | 특히 볼 것 |
|---|---|---|
| 1 | **가입** `register.html` | 약관·개인정보 동의가 실제로 걸리나 · 중복 메일은 뭐라 하나 |
| 2 | **로그인** `login.html` | 틀린 비번 5번 → 🔴 **잠기나** · 잠기면 **뭐라고 말하나** |
| 3 | 🔴 **비번 찾기** `forgot.html` → `reset.html` | 메일이 안 갈 것이다 — **토큰을 DB 에서 읽어** 이어 가라. **그 사실을 적어라**(메일이 진짜 가는지는 «못 쟀음») |
| 4 | 🔴 **아이디(메일) 찾기** | **있나 없나부터 답해라.** 없으면 «없다»가 결론이다(메일=아이디면 불필요할 수 있다 — 어느 쪽인지 적어라) |

## 4. 무엇을 적나 — `docs/active/2026-09-19-scenario-a-walk.md`
단계마다 **한 줄씩**:
- ✅ 됐다 / ❌ 막혔다(**정확히 어디서·무슨 글자가 떴나**) / ⊘ **못 쟀다**(AI·결제·메일처럼 이번에 못 하는 것)
- 🔴 **화면이 한 말을 그대로 옮겨 적어라.** «오류가 떴다»가 아니라 **뜬 문장 그대로**.
- 🔴 **«말이 이상한 데»를 따로 모아라** — 겁주는 말(§3) · 시스템 용어 · «알려만 드립니다» 식 발뺌. 고장만큼 중요하다.
- 🔴 **«초록인데 고장»** — 검사는 통과하는데 손님 눈엔 안 되는 자리. **이게 이 일의 본체다.**
