## 2. 트레이 앱이 풀려던 문제 셋 — 지금 몇 개가 남았나

| 문제 | 지금 상태 | 남았나 |
|---|---|---|
| **창을 닫으면 조용히 멈춘다** | 세 곳이 말한다: 홈 «해야 할 일»(`home-summary.ts:164` · 30분 기준 · «한 번도 안 켰다»와 «꺼졌다»를 가른다) · 알림함 `runner_offline`(`publish-one.ts:131`) · 웹푸시 | ❌ 안 남았다 |
| **콘솔 창이 보기 싫다** | 미관 문제. 🔴 **내 PC 러너는 이제 «기본»이 아니라 «직접 돌리고 싶은 사람의 선택지»**다(§8.1 · 관리형이 기본). 콘솔을 싫어할 사람은 애초에 관리형을 고른다 | 🟡 값이 작다 |
| 🔴 **재부팅하면 안 돌아온다** | **아무도 안 한다.** PC 를 껐다 켜면 고객이 `run.bat` 을 다시 눌러야 한다 | ✅ **남았다** |

⇒ **셋 중 하나만 진짜다.** 그리고 그 하나에 트레이 앱은 필요 없다.

## 3. 왜 «안 만든다»인가 — 값과 값어치

| 드는 것 | 크기 |
|---|---|
| Electron(≈150MB) 또는 네이티브 트레이 — **새 빌드 사슬 하나** | L |
| 🔴 **코드 서명 인증서** — 서명 없는 `.exe` 는 SmartScreen 경고가 뜬다. **콘솔 창보다 나쁜 첫인상**이고, 사는 것은 사장님 결정이다 | 외부 선결조건 |
| 자동 업데이트를 다시 짜야 한다 — 지금은 **zip 교체 + 종료코드 75 재시작**으로 단순하고, 실제로 돈다 | M |
| 맥·리눅스 트레이는 또 따로 | M |

| 얻는 것 | 크기 |
|---|---|
| 콘솔 창이 안 보인다 | 미관 |
| 재부팅 뒤 자동 시작 | 🔴 **이건 바로가기로 된다**(아래) |

**지금 자기 PC 로 러너를 돌리는 실고객은 0명이다.** 설치 UX 에 새 빌드 사슬과 인증서를 먼저 사는 것은 순서가 틀렸다.

## 4. 대신 한 것 — 자동 시작 (**옵트인** · `run.bat --autostart`)

- 시작 프로그램 폴더에 바로가기를 만든다. **`WindowStyle=7`(최소화)** 라 로그인할 때 창이 얼굴로 튀어나오지 않는다 — 콘솔 미관 문제의 절반도 여기서 같이 풀린다.
- **끄기도 같이**: `run.bat --autostart-off`. 🔴 **되돌릴 길 없는 것을 만들지 않는다**(CLAUDE §9-3).
- 🔴 **몰래 켜지 않는다.** 고객이 그 명령을 직접 칠 때만 생긴다.
- 🔴 **«만들었다»를 믿지 않는다** — PowerShell 종료코드가 아니라 **파일이 실제로 있는지 읽어서** 확인한다(AC-66).
  못 만들면 «Win+R → `shell:startup` 에 바로가기를 넣으세요»를 사람말로 안내한다.
- **맥·리눅스는 안 만들었다**(정직). launchd·systemd 는 배포판마다 다르고 **우리에겐 맥도 리눅스 러너도 없다** —
  못 돌려 보는 코드를 배치 파일에 넣는 것이 바로 §5 에서 우리가 밟은 그 지뢰다.

---

## 5. 🔴 이걸 만들다 **진짜 결함을 하나 밟았다** — `run.bat` 이 LF 전용이었다

`--autostart` 를 넣고 **돌려 봤더니** 플래그가 무시되고 러너가 그냥 실행됐다. 원인은 내 코드가 아니었다:

> **`runner/run.bat` 이 LF(`\n`) 전용으로 저장돼 있었다.** cmd.exe 는 배치 파일을 **바이트 오프셋으로 seek** 해서
> `goto` 를 처리한다 — CR 가 없으면 **줄 중간에 착지**하고, 착지한 자리부터를 명령으로 읽는다
> (실측 출력: `'toCreate' is not recognized…` `'--autostart"=="--autostart" goto :autostart_on' is not recognized…`).

- 🔴 **오류 없이 «다른 일»이 일어난다** — 고객은 «자동 시작을 켰는데 안 켜졌다»만 보고, 로그엔 아무것도 없다.
- 이미 있던 `goto :npmfail`·`:tokenfail`·`:runloop` 도 **같은 지뢰 위에** 있었다(짧은 점프라 우연히 살아 있었을 뿐).
- 고침 셋:
  1. `runner/run.bat` → **CRLF**.
  2. **`.gitattributes` 신설** — `*.bat/*.cmd/*.ps1 = crlf` · `*.sh = lf`. 없으면 **다음 체크아웃에서 도로 LF 가 된다**.
  3. 🔴 `scripts/build-runner.mts` 에 **줄끝 검사** — 어긋나면 **빌드를 세운다**.
     `.gitattributes` 는 «git 의 규칙»이고 이건 «실제로 나가는 바이트»다. 둘은 다른 층이고, **«설정했다»는 «그렇다»가 아니다**(AC-66).
     음성 대조로 확인: LF 배치·CR 섞인 셸 **둘만** 떨어지고 정상 둘은 통과.

**이게 §3.5 에서 제일 값나간 것이다.** 트레이 앱을 만들었어도 이 지뢰는 그대로 남았을 것이다.
