# 🔴 «읽는 쪽은 그 칸을 보는데 **쓰는 길이 없다**» — 축을 세웠다 (2026-09-20 · B)

> 브랜치 `audit/read-no-writer-2026-09-20` · **push 안 함**
> 메인이 준 다음 판 첫 몫: «아무도 안 틀렸는데 기능이 없다»를 재는 축.

## 1. 한 자에 두 방향으로 둘까 — **돌려 보고 나눴다**

메인: «네 `verify-upstream-discarded` 의 ②축이 그 반대편(«저장만 하고 아무도 안 읽는 칸»)을 잡는다. 둘이 한 쌍이니 같은 자에 둘까 — 네가 돌려 보고 정해라.»

**나눴다. 재 보고 정한 이유 셋:**

| | 잰 것 | 그래서 |
|---|---|---|
| 모수가 다르다 | 옆 자는 `pieces.meta` **JSON 키**(이름이 길다) · 이 자는 **DDL 칸** 741개(이름이 짧다) | 한 자에 두면 파서 둘이 한 파일에 산다 |
| 🔴 반대 방향은 **DB 칸에서 못 잰다** | 돌려 봤다 — «쓰는데 아무도 안 읽는 칸» **17칸**이 나왔고 **전수 거짓양성**이었다(`ref`·`key`·`ip`·`day`·`enc` 처럼 **세 글자 이름**이라 읽기 판정이 표를 못 가린다) | 그쪽은 이름 긴 `meta` 에서만 잴 수 있고 **그 자가 이미 있다** |
| 세 번째 축도 재 봤다가 접었다 | «계약 머리말에 적힌 요청 칸을 서버가 읽나» — 파일 하나만 보면 **21개가 헛 울고**(핸들러가 몸통을 통째로 `lib/` 에 넘긴다), 부르는 `lib/` 까지 봐 주면 **0개**(늘 초록) | 값이 0이라 안 넣었다. 머리말에 **잰 숫자와 함께** 적어 뒀다(AC-9) |

⇒ 새 자 **`scripts/verify-write-path-missing.mjs`**(3축) · 옆 자와 서로 머리말에서 가리킨다.

## 2. 🔴 자를 세우다 **자가 네 번 틀렸다** — 전부 «멀쩡한 칸을 빨갛게»

처음 재니 **62칸**이 나왔다. 그 중 진짜는 3칸이었다. 나머지는 전부 **자가 쓰기를 못 본 것**이다.

| 무엇이 자를 속였나 | 몇 칸을 헛 울렸나 |
|---|---|
| 읽기를 **표에 안 묶었다** — `tenant_id` 가 있는 질의는 `feature_flags.tenant_id` 를 읽는 걸로 셌다 | 45칸 |
| 🔴 이 리포의 쓰기는 대부분 **`sets.push(sql\`col = …\`)` 조각**이다 — `UPDATE … SET` 만 찾았다 | 6칸 |
| 🔴 **`${…}` 안의 중첩 백틱**을 못 넘어 질의가 거기서 잘렸다(`external_url`·`channel_ref`·`purged_at`·`caps`) | 4칸 |
| `CASE WHEN … THEN` 이 «앞 낱말이 SET 인가» 판정을 속였다 · SQL `--` 주석이 쉼표와 다음 칸 사이를 끊었다 | 2칸 |
| 🔴 **`scripts/` 를 한 덩어리로 봤다** — `seed-*`(씨앗 = 정식 길)와 `verify-*`(시험 = 길 아님)는 다르다 | 1칸 |

**남은 것 3칸 · 거짓양성 0.** 셋 다 손으로 확인했다.

## 3. 잡은 것 — 둘 다 «아무도 안 틀렸는데 기능이 없다»

### ① `accounts.opened_at` — 읽는 곳 6 · 쓰는 곳 0 (이미 메인에 보고한 것)
워밍업이 «계정을 만든 날 > 우리와 연결한 날» 순으로 본다(**설계가 옳다**). 그런데 값을 넣을 길이 없어 6곳이 전부 `created_at` 으로 떨어진다.
🔴 **시험 대본(`scripts/_smoke/r8-soft-gate-smoke.mts`)만 그 칸을 채운다** — 이 집안에서 제일 고약한 얼굴이다. **자를 돌리면 잘 돈다.**

### ② 🔴 `feature_flags` — **영상 킬 스위치를 아무도 못 누른다**(새로 찾은 것)
```
lib/video/cost.ts:12  «kill switch = feature_flags(key='video')(운영센터 AI 메뉴) · 조회 실패(DB) = 차단(fail-closed · 돈 자원)»
lib/video/cost.ts:70  SELECT enabled FROM feature_flags WHERE key = 'video' AND (tenant_id = ${tenantId} OR tenant_id IS NULL)
```
| | 수 |
|---|---|
| 읽는 곳 | 1 (원가 판정이 **매번** 본다) |
| 운영센터 API | **0** |
| 운영센터 화면 | **0** |
| 쓰는 곳 | **0** (`scripts/verify-p1r5.mjs` 가 시험용으로 넣었다 지운다) |

머리말이 «운영센터 AI 메뉴»라 적어 뒀고 **그 메뉴는 실제로 있다**(`ops-ai.ts` — 모델 체인·카나리·자동수동·원가 상한).
**그 줄 하나만 없다.** ⇒ 영상이 돈을 태우기 시작해도 운영자가 **DB 를 손으로 고치는 것 말고는 끌 방법이 없다.**

🔴 이건 §9 의 «게이트»가 아니다 — 고객 계정을 우리가 막는 것이 아니라 **우리 돈·우리 공급자를 우리가 끄는 스위치**다. 이미 `fail-closed` 로 만들어 놓고 **켜고 끌 손잡이만 안 단 것**이다.
고치는 법: `ops-ai.ts` 에 라우트 한 개(`ops-ai-cost-cap` 과 같은 모양) + AI 메뉴에 스위치 한 줄. **메인이 나눌 몫으로 넘긴다**(운영센터는 내 쪽이니 시키면 바로 한다).

## 4. 🔴 변이 11/11 — 그런데 **넷이 헛 울고 있었다**

| 변이 | 무엇을 지키나 |
|---|---|
| M1·M2 | 대조군의 쓰는 길을 들어내면 운다(문턱이 «셋 다») |
| M3 | 안 쓰이던 칸을 **읽기만** 더하면 새 이름이 뜬다 |
| M4 | 🔴 **시험 대본이 써도 «길»이 아니다** |
| M5 | 🔴 **씨앗 대본이 쓰면 «길»이다**(가름이 사나) |
| M6 | 중첩 백틱 안의 쓰기도 본다 |
| M7 | `--` 주석 낀 SET 도 본다 |
| M8 | 기본값 있는 칸은 안 센다(세면 3 → 수십 개로 분다) |
| M9 | «일부러 뺀 칸» 목록이 실제로 먹는다 |
| M10·M11 | 씨앗(seed 대본 · DDL INSERT) 둘 다 길로 친다 |

### 🔴 변이가 자를 고치게 한 것 셋 + **변이 자체가 틀린 것 넷**
- 자를 고친 것: ① `seed-*` 이름에 **밑줄**이 들어가면 시험 대본으로 읽었다(M5) · ② 한 조각이 **두 칸을 쓰면 앞엣것만** 봤다(M7) · ③ 🔴 추출기가 `\` 와 **그 뒤 글자를 통째로 버려** 줄바꿈이 사라지고 `--` 주석이 뒷줄을 먹었다(M7)
- 🔴 **변이가 헛 울었다**: «①축 줄만 본다»고 써 놓고 «쓰는 길»로 줄을 골랐는데 — **자의 제목 줄**(«읽는 쪽은 있는데 쓰는 길이 없나»)이 먼저 걸렸다. «없음»을 보는 변이 **넷(M5·M6·M9·M11)이 공짜로 통과**했다.
  안 울린 게 아니라 **헛 울린 것**이다(AC-112 의 거울: «울었다»도 의심해야 한다 — **무엇을 보고 울었는지**를 봐라).

## 6. 안 한 것
- **고치지 않았다** — 축을 세우는 것이 이번 몫이다. ②는 운영센터라 내 쪽인데 **메인이 창을 나눈다**(§5).
- 화면에 입력칸이 **보이나**는 이 자가 안 본다(서버에 길이 있나까지) — 머리말에 못 박았다.
- `jsonb` 안의 칸(`settings->>'x'`)은 안 본다 — 옆 자(`verify-upstream-discarded`)의 `meta` 축 몫이다.
