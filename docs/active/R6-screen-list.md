## 메인 판단 (2026-09-14)

**① 영수증·세금계산서의 공급자 정보 — 페이지는 만들고, 값은 운영센터에서 넣는다.**
- 사업자 정보를 코드에 박지 않는다. **운영센터 «요금제» 메뉴 아래 «회사 정보»**(상호·대표·사업자등록번호·통신판매업 신고번호·주소·대표 이메일·전화)를 두고 DB 설정에 저장 · 영수증·세금계산서·약관 하단이 **같은 출처**를 읽는다.
- 값이 비어 있으면 영수증 페이지는 **«준비 중이에요»** 한 줄(빨간 오류 아님 · 금액·결제일은 그대로 보인다). «값 생길 때까지 미루기»는 하지 않는다 — 미루면 KICC 키 오는 날 또 한 라운드가 필요하다(«키 꽂으면 즉시» 관례).
- 🔴 사장님 입력 필요: 사업자등록증 상의 **상호·대표자·사업자등록번호·주소** + **통신판매업 신고번호**(§19 법·약관에 이미 있는 항목).

**② 공유 카드는 «금액만 · 핸들 숨김»이 기본이다.**
- 이유: 카드에 계정 핸들이 박히면 **«이 계정은 자동화로 돌아간다»를 공개 게시**하는 셈이다 — DESIGN §16 «자동화 약관 리스크»·§7.3 격리와 정면으로 닿는다(플랫폼이 그 이미지를 근거로 삼을 수 있다).
- 기본 = 금액 + 기간 + 우리 브랜드. 토글 «채널 이름 보이기»·«핸들 보이기» 는 **꺼짐이 기본** · 켤 때 시트에 한 줄 «계정 이름이 함께 보여요».
- 서버 렌더(A 제안) 채택 — 화면 canvas 합성 금지.
