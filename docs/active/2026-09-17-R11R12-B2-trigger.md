# B2-1 (18→40%) 🔴 **자막 모션 넷**

**«구절당 PNG 한 장»은 그대로 둔다.** 🔴 **PNG 를 여러 장 만들지 마라** — 프레임마다 그리면 **원가가 프레임 수만큼 곱해진다.**
한 장을 두고 **ffmpeg 가 그 장의 자리·투명도·크기를 시간에 따라 바꾼다.**

| 이름 | 화면 말 | 어떻게 |
|---|---|---|
| `none` | 없음 | 🔴 **기본값 — 지금 그대로** |
| `fade` | 서서히 | 투명도 0→1 (120~200ms) |
| `slide_up` | 아래에서 올라옴 | y 를 +24px → 0 |
| `pop` | 톡 튀어나옴 | 크기 0.94→1.0 |

🔴 **다섯째를 만들지 마라.** 배워 와도 **우리가 못 내면 장식**이다 — `refUnused` 에 «못 내요»로 적고 `none`.
🔴 **나가는 모션은 안 만든다** — 다음 자막과 겹치면 **두 줄이 동시에 보이고**, 그건 심사의 «자막 2줄» 규칙과 싸운다.
🔴 **모션 길이를 고객이 못 정한다** — 120~200ms 안에서 우리가 정한다. 길면 **읽을 시간을 먹는다**(`judge.ts` `reading_time`).

# B2-2 (40→58%) 🔴 **컷 전환 셋**

지금 `concat` 은 **겹치는 구간이 없다.** 전환을 넣으면 전체 길이가 짧아진다 — 🔴 **0.3초 × 12컷 = 3.6초가 사라진다.**

**규칙 셋**
1. 🔴 **컷 «사이»가 아니라 컷 «안»에서 빌린다** — 각 컷을 전환 길이만큼 **늘려서** 겹친다. **전체 길이는 그대로.**
2. 🔴 **나레이션은 안 건드린다** — 자막·음성 타임스탬프는 원래 값. 전환은 **그림에만.**
3. **전환 상한 0.4초** · 컷이 **0.8초보다 짧으면 건너뛴다**(겹칠 자리가 없다 · `none`).

| 이름 | 화면 말 | ffmpeg |
|---|---|---|
| `none` | 없음 | 🔴 **기본값** |
| `fade` | 부드럽게 | `xfade=transition=fade` |
| `slide` | 밀려남 | `xfade=transition=slideleft` |

⚠️ 🔴 **`xfade` 는 ffmpeg 4.3 이상**이다. **고객 PC 의 판을 먼저 재고**, 낮으면 `none` 으로 내려앉히고 «**이 컴퓨터의 ffmpeg 가 낮아서 전환 없이 만들었어요**»를 적어라(AC-9 · 조용히 버리지 마라 · **막지도 마라** — 영상은 나간다).
