# 🔴 «손님이 검수창에서 고치는 길» 세 번째 걷기 (2026-09-20 · A)

> 메인: «오늘 그 한 동작에서 **서로 다른 창이 각각 고장을 찾았다.** 한 번 더 밟으면 셋째가 나올 수도 있다.»
> ⇒ 밟았다. **둘 나왔다.**

## 0. 어떻게 걸었나
로컬(`_shots/serve-all-local.mts`) · 진짜 브라우저(Chromium 390×844 · ko-KR · Asia/Seoul) · 테넌트 **762**.
AI 0 · 코인 0(직접 쓰기) · 실발행 0. 만든 글: **1982**(승인까지) · **1983·1984**(글자 수 재현·확인).

길: 직접 쓰기 → 검수에서 **제목·본문 둘 다** 고치기 → 수정 저장 → 새로고침 → **이대로 발행 예약** → 편성표 확인.

## 1. ✅ 길 자체는 끝까지 간다
| 단계 | 결과 |
|---|---|
| 고치기 | «수정 저장»이 뜬다 |
| 저장 | `200 /api/pieces-update` · 제목·본문 **둘 다** DB 에 남는다 · 배지 «봐주세요»→«**고쳤어요**» |
| 승인 | `200 /api/pieces-approve {"status":"scheduled","scheduledFor":"2026-09-26T00:00:00.000Z"}` (= **9/26 09:00 KST** · 맞다) |
| 자리 | `slots 991` 이 `scheduled` · `piece_id=1982` 로 묶였다 |
| 글 화면 | 단추가 «지금 올리기»로 바뀐다 |

🔴 **어제 고친 `edited` 갈래가 여기서 값을 했다** — 저장하면 상태가 «고쳤어요»가 되는데, 그때도 «이대로 발행 예약»이 남아 있어서 **승인까지 갈 수 있었다.** 고치기 전이었으면 이 걷기는 ③에서 끝났다.

## 2. 🔴 나온 것 ① — **저장 직후 글자 수가 두 개** (A 가 고쳤다)
같은 화면, 저장 버튼 누른 직후:
```
["지금 글은 50자", "지금 102자"]      ← 서로 다른 값 2개
새로고침 뒤 → ["지금 글은 102자", "지금 102자"]
```
**세는 자는 하나다**(2026-09-19 에 `countPlainChars` 로 모았다). 이번엔 **화면이 새 값을 안 받은 것**이다:
`save()` 가 `P.gate` 는 응답에서 새로 받아 검사 줄을 다시 그리는데, «이 글이 왜 이렇게 생겼나»의 분량 값(`P.contract.actualChars`)은 **불러올 때 받은 옛 값** 그대로였다.

**고친 방법** — 화면이 제 나름대로 세게 하지 않았다(그러면 자가 다시 둘이 된다).
`pieces-update` 가 **같은 자**(`htmlCharCount`/`blocksCharCount`)로 세어 `actualChars` 를 실어 보내고, 화면은 그걸 받아 `renderWhy()` 를 다시 그린다.
실측: 고친 뒤 저장 직후 → `["지금 글은 102자","지금 102자"]` (값 1개).

## 3. 🔴 나온 것 ② — **편성표가 «고친 제목»을 모른다** 〔B 몫〕
승인해서 9/26 자리에 걸린 글의 제목은 «**고친 제목 — 손님이 바꾼 것**»이다. 그런데 편성표는 이렇게 말한다:
> 26일 토요일 · N **수험생 비타민 추천 직장인이 골라본 영양제** · @scenario-a-2026-09-19 · 09:00 예약

그건 그 자리에 **디렉터가 배정했던 소재 제목**(`slots.topic_title`)이다. 손님이 고친 **글 제목이 아니다.**

**서버가 글 제목을 아예 안 보낸다** — `slots-list` 응답에 `topicTitle` 은 있고 `pieceId` 도 있는데 **글 제목 칸이 없다**(`lib/slots.ts:381` 이 `topic_title` 만 싣는다).
⇒ 화면이 고칠 수 있는 자리가 아니다. **`lib/slots.ts` = B 몫**이라 손대지 않았다.

- 같은 집 다른 화면과 **말이 갈린다**: 홈 «오늘 편성»은 **글 제목**을 보여 주고, 편성표는 **소재 제목**을 보여 준다.
- 손님이 겪는 것: 제목을 고쳐 예약해 놓고 편성표를 보면 **딴 글이 걸린 것처럼 보인다.**
- 버린 글(1981)에서도 같다 — 편성표엔 «추석 선물세트…»(소재), 실제 글 제목은 «고친 글이 발행되나 시험».

## 4. ⚠️ 작은 것
- 승인 뒤 `/app/pieces.html?tab=scheduled` 로 넘어가는데 **«예약했어요» 같은 한마디가 안 잡혔다.** 목록이 바뀌는 게 답이긴 하다(문의 보내기와 같은 모양). ⊘ 토스트가 내 관찰 창(9초) 밖이었을 수 있어 «없다»고 단정하지 않는다.
- `pieces-self` 는 본문이 30자 미만이면 «본문이 너무 짧아요. 30자 이상 적어 주세요.»로 막는다 — 사람말이다. ✅
