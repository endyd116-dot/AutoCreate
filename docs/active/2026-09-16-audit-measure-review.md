## 0. 어떻게 쟀나 — 🔴 **제품 파일을 한 글자도 안 건드렸다**

셋이 같은 저장소에서 돈다. 그래서 파일을 고쳐 가며 찌르지 않고, **하니스 사본**(scratchpad)에
읽기 함수만 갈아 끼웠다:

| 손잡이 | 하는 일 | 무엇을 드러내나 |
|---|---|---|
| `AC_HIDE=경로` | 그 파일이 **빈 파일**로 읽힌다(`existsSync` 도 false) | 그 칸이 **정말 그 파일을 읽나** |

## 3. 🔴 찾은 것 — 값이 큰 순서

### ① ④7 `avatar`(계정 사진) — **파일이 통째로 없어져도 «닫힘»** (행 80)

```js
const fixed = inFile("lib/accounts.ts", /avatar:\s*null/);
return fixed ? ["열림", "…고정 — 값이 어디서도 안 온다"] : ["닫힘", "고정값 아님"];
```

- **찔러 본 결과**: `lib/accounts.ts` 를 **통째로 가려도 «닫힘»**. 거꾸로 `avatar: null` 을 한 줄 넣으면 «열림».
- 🔴 이 칸의 «닫힘»은 «계정 사진이 된다»가 아니라 **«내가 아는 나쁜 모양을 못 찾았다»**다.
  파일 이름이 바뀌어도 · 코드가 다른 모양으로 고정값을 써도 · 파일이 지워져도 **초록**이다.
- **고칠 값 🔴 큼**. 없는 기능을 «있다»로 세면 그 숫자가 사장님께 간다.
- **범위(제안만)**: «값이 오는 길이 있나»로 뒤집기 — ⓐ 스키마에 칸이 있나 ⓑ 그 칸을 **읽어 채우는 코드**가 있나
  ⓒ **화면이 그리나**. 셋 다 보면 부정형이 아니라 긍정형이 된다.

### ③ A12 §17 P5(릴스 90초) — **같은 뜻 다른 모양을 못 본다** (행 219)

```js
inFile("lib/video/types.ts", /VideoSeconds = 15 \| 30 \| 60 \| 90/)
```

- 설명줄은 «**`VIDEO_SECONDS` 에 90 없음**»이라고 말하는데, **재는 것은 타입 별칭**이다. 말과 자가 다르다.
- **찔러 본 결과**: 타입 별칭을 그 글자 그대로 넣으면 «닫힘». 🔴 그런데 **실제로 도는 값**
  `export const VIDEO_SECONDS = [15, 30, 60, 90];` 를 넣으면 **«열림» 그대로**.
  ⇒ 90초를 **진짜로 켜도** 타입 줄의 띄어쓰기가 다르면 이 칸은 영영 빨강이다.
- **고칠 값: 중간**. 범위(제안만): 타입 글자 대신 **`VIDEO_SECONDS` 배열에 90 이 있나**로.

# §9. 손잡이 셋 — 메인이 하니스에 넣을 코드 조각

```js
/** 경로 끝맞춤(윈도우 역슬래시도 받는다). */
const acHidden = (p) => AC_HIDE.length > 0 && AC_HIDE.some((h) => String(p).split(String.fromCharCode(92)).join("/").endsWith(h));
const acStrip = (t) => t.replace(/\/\*[\s\S]*?\*\//g, " ").replace(/(^|[^:])\/\/[^\n]*/g, "$1 ").replace(/<!--[\s\S]*?-->/g, " ");
```

`read` 는 **한 줄만** 바뀐다(원래 본문은 그대로):

```js
const read = (p) => {
  if (acHidden(p)) return "";                                   // AC_HIDE
  let t; try { t = readFileSync(p, "utf8"); } catch { return ""; }
  if (AC_STRIP) t = acStrip(t);                                 // AC_STRIP
  for (const [ip, txt] of AC_INJECT) if (String(p).split(String.fromCharCode(92)).join("/").endsWith(ip)) t += "\n" + txt;   // AC_INJECT
  return t;
};
```

`existsSync` 를 부르는 자리는 **감싼 것 하나**로 바꾼다(선언은 `existsSync0` 로 import):

```js
import { readFileSync, existsSync as existsSync0 } from "node:fs";
const existsSync = (p) => (acHidden(p) ? false : existsSync0(p));
```

## 9.2 🔴 «안 켜면 안 바뀐다»를 **말이 아니라 구조로** 보장한다

세 손잡이는 전부 **빈 값일 때 항등식**이다:

| 손잡이 | 안 켰을 때 | 왜 안 바뀌나 |
|---|---|---|
| `AC_HIDE` | `[]` | `acHidden()` 이 **첫 조건에서** `false` — `some()` 조차 안 돈다 |
| `AC_STRIP` | `false` | `if` 안으로 안 들어간다 |
| `AC_INJECT` | `[]` | `for` 가 0바퀴 |

⇒ 셋 다 비면 `read` 는 **원래 `read` 와 글자 그대로 같은 값**을 돌려준다.

🔴 **그래도 말로 믿지 말고 한 번 재라** — 넣은 직후 이것만 돌리면 된다:

```
node scripts/verify-r8-audit64.mjs --json > /tmp/a.json
AC_HIDE= AC_INJECT= AC_STRIP= node scripts/verify-r8-audit64.mjs --json > /tmp/b.json
node -e "const a=require('/tmp/a.json'),b=require('/tmp/b.json');const x=a.results||a,y=b.results||b;let d=0;for(let i=0;i<x.length;i++)if(x[i].state!==y[i].state||x[i].row!==y[i].row)d++;console.log(d?('🔴 차이 '+d):'✅ 손잡이 꺼짐 = 종전과 동일 '+x.length+'줄');process.exit(d?1:0)"
```

🔴 **더 센 확인**: 넣기 **전** 출력을 파일로 떠 두고, 넣은 **뒤** 출력과 견주는 것.
내가 이 문서의 모든 숫자를 그렇게 냈다 — «사본이 원본과 같은 판정을 내는지 **먼저**»(54줄 일치).
그 확인 없이 잰 값은 **자를 잰 것이 아니라 내 사본을 잰 것**이다.
