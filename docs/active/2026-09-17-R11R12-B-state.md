## 4. 🔴 이 환경의 함정 — 밟았고 우회했다

셸이 **역슬래시를 한 겹 먹는다**(AC-100). `python - <<'PY'` 힙독에서 정규식 `/[\n]|[ \t]*/` 를 넣었더니
**정규식 리터럴 안에 생 줄바꿈**이 들어가 `verify-r11-axis.mts` 가 통째로 안 돌았다(그러고도 `grep` 에 아무것도 안 잡혀 «조용히» 지나갈 뻔했다).

⇒ 우회 둘을 썼고, 이 라운드의 파일 수정은 전부 이 방법으로 했다:
1. **패치 스크립트를 `Write` 로 파일에 쓰고 `python <파일>` 로 실행**(셸을 안 지난다) — 역슬래시가 산다.
2. **역슬래시를 아예 안 쓰는 모양**으로 바꾼다 — `noAds()` 는 정규식을 버리고 `split().join()` 으로 갔다.
3. 넣은 뒤 **제어문자 0개**를 셌다(`lib/blocks.ts`·`lib/format-marks.ts`·`verify-r11-axis.mts` 전부 0).
