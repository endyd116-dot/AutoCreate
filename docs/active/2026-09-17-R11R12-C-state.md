## 2. 🔴 이 라운드에 **내 자만** 잡은 것

### ① 자막·제휴 고지·엔드카드가 영상에 안 실린다 (수리됨 · B2 `6d58013`)
- **증상**: `overlay=…:eof_action=pass` + 오버레이 입력이 `-i ov.png` **단일 프레임** ⇒ 즉시 EOF ⇒ 그 뒤로 본편만 통과.
  실측: **프레임 0 에만** 자막이 있고 **프레임 1부터 없다**(ffmpeg 8.1.2).
- **왜 아무도 못 봤나**: B2 의 자는 **ffmpeg 인자**까지 본다 — 인자는 **맞다.** 심사(`judge.ts`)는 계획값을 본다(AC-33).
  «나온 파일»을 보는 자가 없었다.
- **제일 아픈 곳**: 제휴 고지(`disclosureCaption`)가 같은 사슬이다. CLAUDE §9-④ 는 «막지 말고 **대신 넣어 준다**»인데 **넣어 주는 자리가 비어 있었다.**
- 갈린 것: `eof_action=repeat` ✅ · 오버레이 입력에 `-loop 1 -t` ✅ · `eof_action=pass:repeatlast=1` 🔴 안 됨.
- ⚠️ **판 의존일 수 있다** — 8.1.2 한 판에서만 쟀다. «전부 고장이었다»고는 말하지 않는다.
- ⚠️ 🔴 **이미 R2 에 올라간 러너(1.3.0)는 아직 `pass` 다** — 새 판을 올려야 고객에게 간다(사장님 Allow · B2 가 메인에 올림).

  인스타 카드뉴스 계약의 `formats` 는 **다섯**이다(`writing-contracts.ts:343`).
- **왜 아무도 못 잡았나**: deadends TARGETS 는 초록(서버가 부른다) · B 의 격자도 초록(**`format` 경로만** 표본에 있었다 · AC-99 ⑨).

  13칸 전부 일치 — 다섯 format · `post/cardnews`(옛 글) · 🔴 **대조군** `post × {story,steps,listicle} → post`(넓어지지 않았다) · 빈 값·대문자도 안 샌다.
  B 가 `scripts/verify-r11-mutants.mjs`(9변이)에 이 회귀를 **영구로** 박았다 — 합친 트리에서 `0`.

### ④ 한 채널에 규칙이 둘이면 «한 번에 편성» 시트가 하나를 조용히 끈다 (미수리 · A 자리)
두 사실의 결합이다(둘 다 읽어서 확정):
1. `schedule.html:357` `Object.fromEntries(D.rules.filter(…).map(r => [r.channel, r]))` — **채널로 키를 잡아** 같은 채널 둘째 규칙이 **사라진다**

3. 🔴 **shim 을 «인자가 딱 하나일 때»로 좁혀 흉내가 안 먹었다** — 제품은 `-hide_banner -filters` 로 묻는다. 그래서 ⑤ 가 **거짓 빨강**이었다.
4. 🔴 **전환과 모션을 같이 보내 고지 창이 «달라졌다»가 떴다** — 전환은 **배경**을 바꾼다. 대조군은 **모션만** 보내야 한다(거짓 빨강 1건).
5. 🔴 **heredoc 이 `\b` 를 «백스페이스 바이트(0x08)»로 심었다** — AC-100 의 그 예시 그대로. ⇒ 역슬래시 없는 정규식(`[^A-Za-z0-9_]`)으로 다시 썼고 **제어문자 0개**를 셌다.
6. 🔴 **meter 첫 판이 «거저 초록 34건»을 냈다** — `own` 을 안 본 내 판정 버그. **모든 칸이 빨강인 표는 «다 잡는다»가 아니다**(AC-100 ⑦)를 내가 밟았다.
