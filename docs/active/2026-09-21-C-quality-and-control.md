## 3. 🔴 찾은 것 — 손님이 겪는다

### ㉮ 프록시 저장이 고객의 프록시 **비밀번호를 지운다** (AC-212)
칸 다섯이 저마다 옳은데 이어 놓으니 파괴적이다.

```
lib/accounts.ts:171   o.proxyUrl = maskProxyUrl(r.proxy_url)   → "http://host:3128" (user:pass 제거 · 옳다)
accounts.html:214     <input id="px" value="${a.proxyUrl}">    → 가려진 값을 칸에 채운다
accounts.html:237     proxyUrl: ...value.trim() || undefined   → 늘 실어 보낸다
accounts.ts:253       sets.push(sql`proxy_url = ${px || null}`) → 그 값을 쓴다
```
⇒ **«저장»을 한 번만 눌러도 아이디·비밀번호가 영영 사라진다.** 화면은 «저장했어요»라고 한다.
다음 러너 잡은 인증 없는 프록시로 붙어 실패한다(`proxy_down` — 이름까지 이미 있다).
🔴 **AC-160 ① 이 또 맞았다** — A 가 **바로 두 줄 위** `openedAt` 에서 «건드렸을 때만 보낸다»로 고친 그 병이다. 23줄 차이.
🔴 **덤**: `|| undefined` 라 고객이 프록시를 **지울 수도 없다**(빈 칸 → 안 보냄 → 서버는 옛 값 유지).

## 4. ⑶ 「이 실험이 성립하나」 — 된다 (AC-210)

**방법**: 추적 파일을 두 벌 복사 → 팔 A(그대로) · 팔 B(`scripts/`·package.json 빼고 **내용을 전부 비운다**) → 같은 자를 양쪽에서 돌린다.

**판정 셋** (여기 오기까지 내가 두 번 틀렸다)

| | 뜻 |
|---|---|
| ✓ | 빈 팔에서 종료코드가 갈라진다 — 판정이 제품에 달려 있다 |
| 🔴 ✗ | **출력은 달라졌는데 종료코드는 0** — 보고도 «통과»라 했다(모수 0 을 통과로 쓴 것 · AC-141 ②) |
| ⊘ | 출력이 **글자 하나 안 달라졌다**(모수 밖) · 대조군이 애초에 초록이 아니다 · 시간 초과 |

- 🔴 **자기 찌르기를 먼저 했다** — 아는 검체 **셋**(읽고도 늘 초록인 자 · 성한 자 · 아무것도 안 읽는 자)이 ✗·✓·⊘ 로 갈리는 것을 **판정표를 먼저 적고** 맞댄 뒤 전수를 돌렸다(`--selftest` · 종료코드 0).
- 🔴 **내가 두 번 틀렸다**(AC-210 에 남겼다)
  1. «모수 밖»을 **자의 소스에 `"public/"` 같은 글자가 있나**로 짐작했다 → 못 보는 자 둘을 ✗ 로, 보는 자 하나를 ⊘ 로 찍었다. **양쪽으로 틀린 짐작**이다. ⇒ 짐작을 버리고 **두 팔의 출력을 맞댄다**.
  2. 아레나 폴더 이름을 고정으로 뒀다가, 배경에서 전수가 도는 사이 앞에서 한 번 더 돌렸더니 **그 판이 도는 판의 나무를 지웠다.** 결과는 «그 팔에 자가 없다» 35건으로 **그럴듯하게** 나왔다 — 🔴 오염된 판은 «고장»처럼 보인다. 아레나를 `-${pid}` 로 나눠 고쳤다.
- **돌린 결과(자 55개)**: ✓ 44 · 🔴 ✗ **2** · ⊘ 9(모수 밖 5 · 대조군이 초록 아님 3 · 시간 초과 1) · 종료코드 1
  ✗ 둘 = `verify-audit-selftest` · `verify-r8-audit64` — 둘 다 «닫힘»을 **코드가 아니라 표에서** 읽는다.
- ⚠️ 🔴 **이 자의 한계 — ⊘ 가 ✗ 을 숨긴다.** `verify-asset-versions` 는 `public/` 을 **읽고** «파일 49개»를 찍는데,
  내가 파일을 남기고 **내용만** 비워서 그 숫자가 그대로라 출력이 같았고, 그래서 ⊘ 로 떨어졌다.
  사실은 «화면이 한 글자도 안 부르는데 ‘모두 같은 판을 부른다’»의 **헛통과**다.
  🔴 **⊘ 를 «괜찮다»로 읽지 마라** — «이 자가 제 모수를 안 찍는다»는 뜻이고, **찍게 하면 저절로 ✓·✗ 로 갈람다**(AC-114).
- ⚠️ 🔴 **모수의 절반을 못 본다** — 이 자는 `scripts/verify-*.mjs` **92개**만 본다. `verify-*.mts` 가 **71개** 더 있고(B2 쪽이 대부분) tsx 가 있어야 돌며 그중 25개는 R2·DB 자격을 쓴다. **자가 제 입으로 이걸 말하게 해 둑다.**

🔴 더 나쁜 것은 **그럴듯함**이다 — 판 번호를 어제→오늘로 올리는 것은 정상 빌드처럼 보여, 다음 `git add -A` 에 조용히 실려 **캐시 무효화 배포**가 된다.
⇒ 되돌렸고(`git restore`), 커밋에 안 실렸다. 몴은 A — 변이를 **사본 폴더**에서 돌리면 끝난다.
