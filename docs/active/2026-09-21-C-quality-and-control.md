## 3. 🔴 찾은 것 — 손님이 겪는다

### ㉮ 프록시 저장이 고객의 프록시 **비밀번호를 지운다** (AC-212)
칸 다섯이 저마다 옳은데 이어 놓으니 파괴적이다.

```
lib/accounts.ts:171   o.proxyUrl = maskProxyUrl(r.proxy_url)   → "http://host:3128" (user:pass 제거 · 옳다)
accounts.html:214     <input id="px" value="${a.proxyUrl}">    → 가려진 값을 칸에 채운다
accounts.html:237     proxyUrl: ...value.trim() || undefined   → 늘 실어 보낸다
accounts.ts:253       sets.push(sql`proxy_url = ${px || null}`) → 그 값을 쓴다
```
⇒ **«저장»을 한 번만 눌러도 아이디·비밀번호가 영영 사라진다.** 화면은 «저장했어요»라고 한다.
다음 러너 잡은 인증 없는 프록시로 붙어 실패한다(`proxy_down` — 이름까지 이미 있다).
🔴 **AC-160 ① 이 또 맞았다** — A 가 **바로 두 줄 위** `openedAt` 에서 «건드렸을 때만 보낸다»로 고친 그 병이다. 23줄 차이.
🔴 **덤**: `|| undefined` 라 고객이 프록시를 **지울 수도 없다**(빈 칸 → 안 보냄 → 서버는 옛 값 유지).

### ㉯ `ops-proxies` 를 부르는 화면이 **0곳**
`/api/ops-proxies` · `/api/ops-proxy-assign` 가 있는데 `public/**` 어디도 안 부른다.
운영자가 프록시를 등록·배정할 길이 없다 — CLAUDE §4.8 «API 로만 실증한 기능은 없는 기능».

### ㉰ 못 불러오면 **뼈대가 영원히 남는다** — 19개 중 **13개**
`if (!r.ok) { UI.toast(...); return; }` — 알림은 몇 초 뒤 사라지고, 회색 뼈대는 계속 돌고, **다시 누를 곳이 없다.**
`accounts · create · director · home · piece · pieces · plan · posts · runner · team · ops/audit · ops/tenants · ops/ticket`
치우는 화면은 **1개**뿐. ⊘ 못 잰 화면 5개. (`node scripts/verify-quality-grade.mjs --all`)
🔴 **거짓말하는 화면은 빈 화면보다 나쁘다.**

## 4. ⑶ 「이 실험이 성립하나」 — 된다 (AC-210)

**방법**: 추적 파일을 두 벌 복사 → 팔 A(그대로) · 팔 B(`scripts/`·package.json 빼고 **내용을 전부 비운다**) → 같은 자를 양쪽에서 돌린다.
**판정**: 둘 다 종료코드 0 = ✗ · 갈라지면 ✓ · 대조군이 애초에 초록이 아니면 ⊘(잴 자격 없음).

- 🔴 **자기 찌르기를 먼저 했다** — «제품을 안 읽고 늘 초록인 검체»와 «읽고 없으면 우는 검체»로 ✗/✓ 가 갈리는 것을 보고 전수를 돌렸다.
- 🔴 **첫 전수의 ✗ 7 중 셋이 내 탓**이었다 — `scripts/` 만 읽는 자들을 «눈멀었다»고 찍었다. 자가 읽는 나무를 소스에서 뽑아 **«내가 비운 곳을 보기는 하나»**를 먼저 묻게 고쳤다(⊘ 모수 밖).
- **남은 빨강은 전부 «모수 0 을 통과로 쓴 것»**(AC-141 ②): `verify-asset-versions` · `verify-server-words` · `verify-mutant-residue` · `verify-r8-audit64`.
  처방은 «지워라»가 아니라 **«모수를 찍어라»**(AC-114) — 0개를 셌으면 0개라고 말하면 ⊘ 가 되고, ⊘ 는 사람이 본다.
