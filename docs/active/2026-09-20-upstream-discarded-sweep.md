🔴 **CLAUDE §9 가 «게이트보다 나쁘다»고 한 바로 그 자리다.**
> «**막지 않는 대신 «말해 주기»가 더 세져야 한다** … 막지도 않으면서 불안만 준다» 보다 더 나쁜 것 — **막지도 않고 말하지도 않는다.**

**고친 것**: `netlify/functions/pieces.ts` 의 허용 목록에 한 줄. 모양은 `string[]`(사람말 한 줄씩)이라
A 가 `refUnused`·`formatUnused` 에 쓰는 **칩 줄을 그대로** 쓸 수 있다(새로 지을 것 없다).
비어 있으면 키를 안 싣는다(«없음»을 «[]»로 보내면 화면이 빈 칸을 그린다 — 옆줄과 같은 규율).

🔴 **A 에게 넘길 한 줄**: `P.meta.scriptIssues` 가 `string[]` 로 온다 — `#refunused` 칩 줄과 같은 자리에 그리면 된다.
**그려지기 전까지는 «고쳤다»가 아니다**(CLAUDE §4.8) — 그래서 이 문서에 «화면은 A 몫»이라고 남긴다.
