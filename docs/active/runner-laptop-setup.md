# 러너 노트북 설치 — 그 자리에서 5분 · 2026-09-15

> **AM 러너가 돌고 있는 그 노트북**에 AutoCreate 러너를 **따로** 올립니다.
> 🔴 **AM 쪽은 아무것도 건드리지 않습니다.** 폴더도 설정도 그대로 둡니다 — 다른 폴더에 따로 깔고, 다른 이름으로 등록합니다.
> 왜 따로 까느냐는 `2026-09-15-runner-colocation.md` §2 에 있습니다(한 덩어리로 만들면 우리 업데이트가 AM 발행을 끌고 넘어집니다).

---

## 준비물 — 2가지

1. **앱 화면 하나**: AutoCreate → 설정 → 내 PC 프로그램 → «내 PC에서 켜기»
   (여기서 **열쇠**와 **프로그램 받기** 버튼이 나옵니다. 열쇠는 한 번만 보여 줍니다.)
2. 그 노트북에 **Node.js 20 이상** — 없으면 [nodejs.org](https://nodejs.org) LTS.
   👉 이미 AM 러너가 돌고 있다면 **이미 깔려 있습니다.** 확인: `node -v`

---

## 1단계 — 받아서 풀기 (1분)

1. 그 노트북에서 앱에 로그인 → **«프로그램 받기»** → `autocreate-runner-….zip` 이 받아집니다.
2. 받은 zip 을 **`C:\` 에 바로** 풀어 주세요.
   - 파일 우클릭 → «압축 풀기» → 위치를 **`C:\`** 로.
   - zip 안이 이미 `autocreate-runner` 폴더 한 겹이라, 풀면 **`C:\autocreate-runner\`** 가 생깁니다.
   - 확인: **`C:\autocreate-runner\run.bat`** 이 보이면 맞습니다. (폴더를 더 만들 필요 없습니다.)

> 🔴 **AM 러너 폴더에 풀면 안 됩니다.** 같은 폴더에 섞이면 두 프로그램이 서로의 로그인을 쓰게 됩니다.
> 🔴 폴더 이름에 한글·띄어쓰기를 피해 주세요(`C:\autocreate-runner\` 그대로가 가장 안전합니다).

## 2단계 — 켜고 열쇠 넣기 (2~3분)

1. `C:\autocreate-runner\run.bat` 을 **두 번 클릭**.
2. 처음 한 번은 준비에 몇 분 걸립니다(브라우저를 받습니다 — AM 것과 **같은 걸 나눠 쓰므로** 이미 있으면 빨리 끝납니다).
3. `Key:` 가 나오면 앱에서 복사한 **열쇠**를 붙여넣고 Enter.
4. `Running. Keep this window open.` 이 보이면 끝. **이 창을 닫지 마세요.**
5. 앱 화면에서 이 기기가 **«켜짐»** 으로 바뀌는지 확인해 주세요.

## 3단계 — 컴퓨터를 켤 때 자동으로 (1분)

**관리자 권한 명령 프롬프트**에 아래 한 줄:

```
schtasks /create /tn "AutoCreate Runner" /tr "C:\autocreate-runner\run.bat" /sc onlogon /rl highest /f
```

> 이름을 **«AutoCreate Runner»** 로 넣는 이유: 나중에 «러너가 두 개 도는데 어느 게 뭐지»를 5초에 알기 위해서입니다.

## 4단계 — 노트북이 자면 안 됩니다 (30초)

```
powercfg /change standby-timeout-ac 0
powercfg /setacvalueindex SCHEME_CURRENT 4f971e89-eebd-4455-a8de-9e59040e7347 5ca83367-6e45-459f-a27b-476b1d01c936 0
powercfg /setactive SCHEME_CURRENT
```

- 첫 줄: 절전으로 안 들어갑니다(자면 예약한 글이 그 시간에 안 나갑니다).
- 둘째·셋째 줄: **덮개를 닫아도 계속 돕니다**(노트북을 덮어 두고 쓰실 테니까요).
- 화면이 꺼지는 건 괜찮습니다 — 그냥 두셔도 됩니다.

---

## 다 됐는지 확인 — 6가지

- [ ] `C:\autocreate-runner\run.bat` 창에 `Running. Keep this window open.`
- [ ] 앱 → 설정 → 내 PC 프로그램에 이 기기가 **«켜짐»**
- [ ] 작업 스케줄러에 **«AutoCreate Runner»** 가 보인다(`schtasks /query /tn "AutoCreate Runner"`)
- [ ] 🔴 **AM 러너 창이 그대로 돌고 있다**(아무것도 안 바뀌었다)
- [ ] 🔴 AM 폴더에 새 파일이 생기지 않았다
- [ ] (프록시를 샀다면) 앱의 기기 상세에서 **나가는 IP** 가 산 IP 로 보인다

---

## 되돌리기 — 흔적 없이 (1분)

```
schtasks /delete /tn "AutoCreate Runner" /f
rd /s /q C:\autocreate-runner
```
그리고 앱 → 설정 → 내 PC 프로그램 → 그 기기 **«연결 해제»**.

> 🔴 이 셋이면 **AM 에는 아무 흔적도 남지 않습니다.** 브라우저(Chromium)만 공용 폴더에 남는데, 그건 AM 러너가 쓰던 것이라 그대로 두시면 됩니다.

---

## 안 될 때

| 화면에 나온 말 | 뜻과 할 일 |
|---|---|
| `Node.js is not installed` | Node 20 LTS 를 설치하고 `run.bat` 을 다시 두 번 클릭 |
| `No key entered` | 열쇠를 못 읽었습니다. 앱에서 열쇠를 다시 복사해 주세요(공백이 섞이지 않게) |
| `러너 열쇠가 올바르지 않아요` | 기기가 지워졌거나 열쇠가 바뀌었습니다 → 앱에서 다시 등록 |
| `이 열쇠는 다른 PC에 연결돼 있어요` | 그 열쇠는 다른 컴퓨터에 묶여 있습니다 → 앱에서 **«열쇠 다시 받기»** |
| 한글이 깨져 보인다 | v1.1.5 이상이면 안 깨집니다. 창을 닫고 `run.bat` 을 다시 실행해 주세요(자동으로 최신판을 받습니다) |
| AM 이 갑자기 느려졌다 | 영상 만들기가 돌고 있을 수 있습니다 → 그 창에 «영상» 이 보이면 끝날 때까지 기다리거나, 알려 주시면 영상은 밤에만 돌게 바꾸겠습니다 |

## 알아 두실 것 2가지

1. **업데이트는 저절로 됩니다.** 창에 `Updated - restarting …` 이 잠깐 보이고 다시 돕니다. 다시 받으실 필요 없습니다.
2. **이 노트북 하나에 계정이 많이 몰리면 위험합니다.** 같은 인터넷 회선으로 나가기 때문입니다 —
   그래서 계정마다 전용 IP(프록시)를 붙이는 게 원칙이고, 아직 안 샀다면 이 노트북에는 **계정 3개까지만** 두는 것을 권합니다.
   자세한 이유와 값은 `2026-09-15-proxy-cost.md`·`2026-09-15-runner-colocation.md` §5 에 있습니다.
