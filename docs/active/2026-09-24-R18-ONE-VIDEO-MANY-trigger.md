사장님이 구글 앱을 등록하시는 날 이 기능이 있으면 **처음부터 여러 곳에 나간다.**

## 1. 🔴 사장님 결정을 화면으로 — 정확히 이 모양

### ① «처음 한 번 묻고, 그 뒤론 자동»
```
[첫 영상이 완성됐을 때 — 딱 한 번]
  유튜브 쇼츠에 올릴 준비가 됐어요
  다른 곳에도 올릴까요?
    ☐ 인스타 릴스   ☐ 틱톡   ☐ 네이버 클립
    ☑ 앞으로도 이렇게 할게요          ← 기본 체크
  [ 이대로 예약 ]

[두 번째부터] 안 묻는다. 고른 곳에 그대로 나간다.
[설정] «영상을 여러 곳에 올리기» — 켜고 끄고 채널 고르기. 언제든.
```
· 🔴 **기본은 꺼짐이다** — 처음 한 번은 **반드시** 묻는다. 고객이 «내가 켰다»를 알아야 한다(§9 ②).
· 🔴 **자동 승인 경로에서도 닿아야 한다**(§9 ②) — 사람이 안 보는 경로면 «처음 한 번 묻기»가 아무에게도 안 닿는다.
  ⇒ 자동 승인이 켜진 계정은 **처음 켤 때 알림**으로 묻는다. 답이 없으면 **꺼진 채로 둔다**(모르면 안 켠다).

### ② «안 맞는 채널만 빼고 말해 준다»
```
  60초로 만든 영상
    유튜브 쇼츠 ✅   인스타 릴스 ✅   틱톡 ✅
    네이버 클립 —    이 영상은 60초라 클립(최대 30초)엔 안 올라가요.
                     클립에도 올리시려면 만들 때 30초를 골라 주세요.
```
· 🔴 **§3 말투**: ①사실 한 줄(«60초라 30초짜리엔 안 들어가요») ②어떻게 하면 되는지(«30초를 골라 주세요»). «실패»·«오류»·«불가» 금지.
· 🔴 **만들 때 미리 보여 준다** — 길이를 고르는 그 자리에서 «30초면 네 곳 · 60초면 세 곳»을 **먼저** 말해 준다.
  나중에 빠진 걸 알면 늦다(§9 ① «또렷하게»).
· 🔴 **코인은 한 번**(§4.7 «승계 무료») — 빠진 채널을 위해 **다시 뽑지 않는다.**

## 3. 🔴 **함정 — 유튜브 긴 영상은 «재사용 대상»에서 뺀다**

유튜브는 **2024-10-15 부터 세로·정사각 영상 3분 이하를 자동으로 쇼츠로 분류**한다(업로드 방법·해시태그 무관 · [YouTube 도움말](https://support.google.com/youtube/answer/15424877?hl=en)).
그리고 우리 `youtube_long` 은 **쇼츠와 같은 API·같은 동의·같은 쿼터**다(`channel-registry.ts:164`).

⇒ 쇼츠용 세로 영상을 `youtube_long` 에도 보내면:
- 🔴 **긴 영상이 되지 않는다 — 쇼츠가 하나 더 생긴다**(같은 유튜브 채널에 **같은 영상이 두 번**)
- 🔴 **하루 5건 쿼터를 두 배로 먹는다** — 고객 전체가 나눠 쓰는 통이다(§2.2 · 운영 기본값 5)

⇒ **`youtube_long` 은 세로 짧은 영상의 재사용 대상 목록에 넣지 않는다.** 화면에도 안 띄운다.
   🔴 이건 게이트가 아니라 **없는 길**이다(§9 «이 규칙 밖») — 올려도 긴 영상이 안 되니 **길 자체가 없다.**

## 4. ⚠️ 이 판에서 **안 건드린다** — 사장님 결정이 따로 필요하다

🔴 **유튜브 쇼츠는 이제 3분까지 된다**(위 도움말). 우리 표는 **60초**다.
- 이건 **틀린 값인지 우리 계약인지 적혀 있지 않다** — 주석이 없다.
- 🔴 **그리고 혼자 못 바꾼다** — `writing-contracts.ts:484` 주석이 이미 경고했다:
  **«셋이 같이 움직여야 한다: 이 표 · 코인 값(`coin-table.ts`) · 심사 축(`judge.ts duration_fit`). 따로 가면 «90초인데 값은 60초»가 되고 그건 우리가 손해 보는 쪽이라 더 늦게 들킨다.»**
- ⇒ **R18 에선 60 그대로.** 올릴지는 코인 값과 같이 **사장님께 따로 여쭌다.**

## 6. 🔴 같이 지킬 것

1. **코인은 한 번**(§4.7 «승계 무료»). 🔴 **자로 박는다** — 파생 piece 가 코인 원장에 **0행**인지.
2. **발행 멱등**(§4.7) — 파생도 `channel_ref`/`external_url` 있으면 재게시 금지.
3. **캐던스**(§4.7) — `daily_cap`·`min_gap`·같은 채널 계정 간 30분. **N곳이 한꺼번에 나가지 않는다.**
4. **유튜브 쿼터**(§2.2) — 재사용 때문에 쿼터가 늘어나는 경로가 없어야 한다(§3 에서 `youtube_long` 을 뺀 까닭).
5. 🔴 **§4.8** — 설정 화면에서 **켜고 끄고 채널 고르기**까지가 이 기능이다. API 만 있으면 없는 기능이다.
6. 🔴 **§9** — 막지 않는다. «이 채널엔 안 맞아요»는 **말해 주기**다. 고객이 원하면 **30초로 다시 만들 길**을 같이 준다.

## 9. 보고 — R17 에서 고친 양식(B·B2 가 짚었다)
```
■ 맡은 것: N
■ ㉮ 만들어서 닫았다: X        ← 🔴 이 판에 코드를 쓴 것만
■ ㉰ 원래 돼 있었다(정정):  V   ← 코드 0줄 — «만든 것»과 섞지 마라
■ 아직 열림: Y
■ ⊘ 못 했다: W — 무엇이 막았나
   X+V+Y+W = N 인가?
```
🔴 **«닫았다» 한 칸에 두 뜻을 담으면 어느 쪽으로든 거짓말이 된다**(B). 사장님은 «너희가 뭘 했나»를 이 수로 보신다.
🔴 **검산 수를 넘길 땐 «무엇을 · 어디서 · 몇»**(AC-262 · B2) — 범위 없는 수는 «짝이 맞는 것»을 «샜다»로 읽게 만든다.
