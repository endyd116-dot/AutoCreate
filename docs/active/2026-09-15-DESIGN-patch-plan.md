**한 줄로**: **만드는 데까지는 다 된다(결제·코인·소재·디렉터·글·검수·예약). 한 번도 안 지나간 곳은 «실제 발행»과 «API 수익 회수» 둘이고, 영상은 문이 잠겨 있다.**
그래서 R7 의 §2.1(실발행 첫 통과)·§1(영상 개통)이 **로드맵 Phase 1·2·3·4 를 동시에 여는 유일한 열쇠**다 — 새 기능이 아니라 «한 번 통과시키기»가 남은 일이다.

**이 표를 다시 잴 때 쓰는 질의**(읽기 전용 · 같은 숫자를 다시 만들 수 있게)
```sql
SELECT channel, status, COUNT(*), COUNT(external_url) FROM posts GROUP BY 1,2;          -- 발행이 실제로 됐나(URL 이 localhost 면 하니스다)
SELECT source, freshness, COUNT(*), SUM(amount_krw) FROM revenue_daily GROUP BY 1,2;    -- 수익이 어느 손으로 들어왔나
SELECT status, string_agg(key, ',' ORDER BY sort) FROM channel_registry GROUP BY 1;     -- 영상 문이 열렸나
SELECT status, COUNT(*), SUM(COALESCE(total_krw, amount)) FROM invoices GROUP BY 1;     -- 실돈이 돌았나
SELECT COUNT(*) FROM slots WHERE status = 'reassigned';                                  -- 승계가 실제로 옮겼나
```
