# B 트리거 — 🔴 «운영자»가 되어 운영센터를 전부 눌러 본다 (2026-09-19 · 사장님 지시)

## 0. 왜
운영 화면 **18개** · 운영 API **18개** 가 코드에 있다. 🔴 **그런데 실제로 손님 한 명을 붙잡고 처리해 본 적이 없다.**
«첫 손님이 들어왔을 때 우리가 그 사람을 다룰 수 있나»가 이번 물음이다.

## 1. 어디서 도나 — **로컬. 푸시 안 한다**
```
npx netlify dev
```
- DB 는 **라이브 Neon**. ⇒ **네가 하는 처리는 진짜 처리다.** §2 를 반드시 지켜라.
- 🔴 **A 가 같은 시각에 «손님» 시나리오를 돈다.** A 가 만드는 `scenario-a-*` 테넌트를 **네 실습 대상으로 써라** — 서로 다른 테넌트를 만들지 말고 **그 하나를 같이 쓰면** «가입한 사람을 운영자가 다루는» 진짜 모양이 된다.
  A 가 아직 안 만들었으면 `scenario-b-<날짜>` 로 네가 하나 만들어서 시작하고, 나중에 A 것으로 한 번 더 해 봐라.

## 2. 🔴 절대 선
- 🔴 **보존 테넌트 3·13·109·116·198(+451) 은 읽지도 쓰지도 마라.** 운영 화면에서 **그 행을 클릭도 하지 마라**(임퍼가 붙는다).
- 🔴 **`ai_usage` 는 어떤 경우에도 안 지운다.**
- 🔴 **실결제·환불 금지.** 결제 화면은 **보기까지**.
- 🔴 **공개 토글·요금제 공개·프로모션 공개 금지** — 라이브에 영향이 간다. 만들어 두고 **비공개**까지.
- 🔴 **내리기(takedown) 실행 금지** — 바깥 채널에 닿는다. 화면과 «누르기 직전»까지.
- **push 금지.** commit 만.
