사장님 지시: «한국 시장에서 각 매체별 말투와 모습들을 **모조리 서칭·학습**한 다음, 지금 우리 글·영상 에디터 구성이 **제대로 되어 있나부터 검증**하고 디벨롭해라.»
결론 한 문장: **«우리 계약은 실물이 아니라 SEO 블로그가 말하는 이상적인 글을 베끼고 있었다.»**

조사 정본 3개(먼저 읽어라): `2026-09-15-R8A-voice-text.md`(글·B-1) · `…-voice-video.md`(영상·B2) · `…-voice-policy.md`(정책·B3).
설계 반영본: `docs/DESIGN.md` **§5C.5**(신설) · §6.2 · §16B.1 · §16B.3.

🔴 **이 라운드의 검증은 «코드가 도는가»가 아니라 «바꾼 것이 진짜로 글·영상에 나타나는가»다.**
B-1 이 실호출 2편으로 이미 배운 것(PITFALLS **AC-63**): **계약 문장만 고치면 생성이 안 따라온다.** 프롬프트 ②칸이 «블록 시퀀스를 순서·개수 그대로 채운다»로 강제하기 때문에 **규칙과 구조가 부딪치면 구조가 이긴다.**
⇒ 네 검사의 기본형은 **«한 줄 바꾸고 → 실제 산출물이 바뀌는지 음성 대조(바꾸기 전/후)»** 다. «프롬프트에 들어갔다»는 **증거가 아니다.**

## §1 글 — 계약이 실제 생성에 닿는가 (제일 중요)

정본: `lib/writing-contracts.ts` · `lib/content-gen.ts` · `lib/structure-print.ts` · `lib/ai-tell-gate.ts`

| # | 무엇을 | 어떻게(대조 방법) | 통과 기준 |
|---|---|---|---|
| 1.1 | **`goalRules` 가 글을 실제로 바꾸나** | 같은 소재·같은 채널로 `goal` 만 `adpost`/`adsense`/`affiliate` 셋으로 돌려 **산출물 3개를 나란히** | 셋이 **서로 다르다**. 특히 affiliate 만 고지가 첫머리에 온다. 🔴 같으면 그게 결함이다(사장님 질문의 답이 거짓이 된다) |
| 1.2 | **`briefs.goal` 이 끊기지 않고 닿나** | `briefs.goal` → `content-gen` 프롬프트까지 **사슬 전 구간 grep**(AC-56 «적재-읽기가 다른 파일인 사슬») | 중간에 떨어지는 자리 0. 떨어지면 **어느 파일에서**인지 적어라 |
| 1.3 | **골격 가짓수가 정말 11~32 인가** | 채널별로 seed 를 바꿔 **20편치 골격만** 뽑아 `structurePrint` 를 센다(실호출 0 · 순수 함수) | 블로거·워드프레스가 **4편째에 겹치지 않는다**. 겹치면 `applyTiers` 가 안 먹는 것이다 |
| 1.4 | **`structure_repeat`(소프트)가 진짜 잡나** | 🔴 **음성 대조** — 일부러 골격이 같은 글 두 편을 만들어 넣어 본다 | 빨강이 뜬다. 🔴 «아무 일 없음»으로 통과를 증명하지 마라(AC-60) |
| 1.5 | **`similarity` 와 `structure_repeat` 가 다른 것을 보나** | 단어만 바꾼 두 편 / 골격만 같은 두 편, 네 조합 | 전자는 similarity 가, 후자는 structure_repeat 가 잡는다(서로 대신하지 못한다) |
| 1.6 | **`lengthByGroup`·`imagesByGroup` 이 적용되나** | `topicGroupOf()` 가 셋으로 갈리는 소재 3개 · 분량·사진 수 비교 | 주제군마다 다르다. group 이 null 이면 **채널 고정값**으로 떨어진다(무회귀) |
| 1.7 | 🔴 **축 이름과 실제가 같나**(AC-57 전수) | `ai-tell-gate.ts` 15축 **하나하나** — 이름이 말하는 것과 코드가 재는 것 | 갈린 축 0. 갈리면 이름을 고칠지 코드를 고칠지 적어라 |
| 1.8 | **끝맺음이 «행동 유도 한 줄»로 나오나** | 실물 대조(조사 §2.2) · `endWithAction` 적용 전/후 | faq 로 끝나지 않는다 |
