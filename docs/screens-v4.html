AutoCreate 화면 시안 v4

v3 를 뿌리로, 구현(P1R1~R3)에서 굳어진 것을 시안 쪽에 옮겨 적고 시안에 없던 화면 7장을 더했다. P1R4 에서 운영센터 «우리 매출» 데스크 1장(맨 아래)을 더했다 — 운영센터의 픽셀 정본. P1R5(영상 축) 착수 전 3장 — 디렉터 영상 행+손보기 시트 · 검수 영상 플레이어 · 발행함 «비공개 업로드됨» — 을 계약 v5.0 §3 대로 미리 그렸다. 규칙은 v3 그대로 — 회색 바탕 위 흰 섹션 R20, 문장형 헤드라인 하나, 색은 채널·매체 마크와 홈의 «번 돈» 초록에만. v4 에서 정한 것: 앱바에 제목 텍스트를 두지 않는다(제목은 헤드라인이 맡는다) · 그룹 제목 우측 링크는 섹션당 1개 · 2~3자 + › · 감소는 잉크 중립(초록은 증가에만) · 알약 낱말은 «발행됨» «예약». 온보딩·디렉터·만들기는 v3 그대로다.
