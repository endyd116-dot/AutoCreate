# 내 PC에서 켜기

AutoCreate가 네이버 블로그·티스토리에 글을 올리려면 **내 PC의 브라우저**가 필요해요.
두 채널은 글쓰기 API가 없어서(네이버는 없고, 티스토리는 2024년 2월에 닫혔어요) 사람이 하듯 창을 열어 올립니다.

이 프로그램이 하는 일은 하나예요 — **앱이 만들어 둔 글을, 예약한 시각에, 내 계정으로 올린다.**

---

## 준비물

- Windows 10 이상 (Mac·Linux도 됩니다 — 아래 «다른 운영체제» 참고)
- **Node.js 20 이상** — 없으면 [nodejs.org](https://nodejs.org)에서 LTS 버전을 받아 설치해 주세요
- 앱에서 받은 **토큰** (`acr_`로 시작하는 글자. 앱 → 설정 → 러너 → «내 PC에서 켜기»)

> 토큰은 **한 번만** 보여 드려요. 창을 닫으면 다시 볼 수 없으니, 못 받았으면 기기를 지우고 다시 등록해 주세요.

---

## 켜는 법 (Windows)

1. 받은 폴더에서 **`run.bat`을 두 번 클릭**하세요.
2. 처음 한 번은 준비에 몇 분 걸려요(브라우저를 내려받습니다).
3. 토큰을 물어보면 붙여넣고 Enter.
4. «Running. Keep this window open.»이 보이면 끝났어요. **이 창을 닫지 마세요.**

컴퓨터를 켤 때 자동으로 실행하려면: `Win + R` → `shell:startup` → 열린 폴더에 `run.bat` **바로가기**를 넣어 주세요.

---

## 확인해 보기

| 하고 싶은 것 | 명령 |
|---|---|
| 대기 중인 일이 있나 보기 | `node ac-runner.mjs --peek` |
| 한 건만 처리해 보기 | `node ac-runner.mjs --once` |
| 창을 띄워 눈으로 보기 | `node ac-runner.mjs --once --headed` |
| **올리지 않고** 임시저장까지만 | `node ac-runner.mjs --once --headed --dry-run` |
| 단계별 사진 남기기 | `RUNNER_SHOTS=1` (Windows: `set RUNNER_SHOTS=1`) → `runner/_shots/` |

> `--dry-run`은 글을 **올리지 않아요**. 임시저장까지만 하고 그 일감을 다시 대기열로 돌려놓습니다.
> 셀렉터가 살아 있는지 보고 싶을 때 안전하게 쓰세요.

---

## 계정 로그인이 필요하다고 나오면

네이버·티스토리가 «자동입력 방지(캡차)»나 «처음 보는 기기»를 물을 때가 있어요.
그럴 땐 앱이 «다시 로그인이 필요해요»라고 알려 드립니다.

1. 앱 → 계정 → 해당 계정의 **«다시 로그인»**
2. 이 프로그램이 **창을 띄웁니다** — 거기서 직접 로그인해 주세요(캡차도 직접 풀어 주세요)
3. 로그인이 끝나면 자동으로 저장돼요. 다음부터는 로그인 단계를 건너뜁니다.

> 비밀번호는 우리 서버에 **암호화해서** 보관하고, 이 프로그램이 일을 받을 때만 잠깐 내려받아 씁니다.
> 화면·기록에는 남기지 않아요.

---

## 자주 묻는 것

**창을 닫아도 되나요?**
아니요. 닫으면 예약한 글이 올라가지 않아요. 앱 홈에 «러너가 꺼져 있어요»가 뜹니다.

**여러 계정을 쓰는데 섞이지 않나요?**
계정마다 **따로 된 브라우저 프로필**(`runner/profiles/`)을 쓰고, 글 하나마다 창을 새로 엽니다. 섞이지 않아요.

**컴퓨터가 느려지나요?**
글을 올리는 몇 분 동안만 브라우저가 뜹니다(보이지 않게). 평소에는 60초에 한 번 서버에 «할 일 있나요»만 물어봐요.

**다른 운영체제(Mac·Linux)**
```bash
cd runner
npm install
npx playwright install chromium
node ac-runner.mjs --token acr_...   # 처음 한 번
node ac-runner.mjs                    # 계속 돌기
```

**기기를 바꿨어요**
앱에서 예전 기기를 지우고 새로 등록해 주세요. 토큰은 기기마다 다릅니다.

## 잘 안 될 때

| 화면에 나온 말 | 뜻과 할 일 |
|---|---|
| `러너 토큰이 올바르지 않아요` | 토큰이 지워졌거나 기기가 삭제됐어요. 앱에서 다시 등록해 주세요. |
| `브라우저 도구(playwright)가 설치되지 않았어요` | `npm install` → `npx playwright install chromium` |
| `서버에 연결하지 못했어요` | 인터넷을 확인해 주세요. 계속되면 잠시 뒤 자동으로 다시 시도합니다. |
| `글쓰기 화면을 찾지 못했어요` | 채널이 화면을 바꿨을 수 있어요. **우리가 고칠 부분**이라 담당이 확인합니다(앱에도 같은 사유가 남아요). |
| `자동입력 방지(캡차)가 떴어요` | 위 «계정 로그인이 필요하다고 나오면» 대로 한 번만 직접 로그인해 주세요. |

문제가 계속되면 앱 → 설정 → 문의하기로 알려 주세요. **`runner/_shots/` 폴더의 사진**을 함께 보내 주시면 훨씬 빨리 찾습니다.
