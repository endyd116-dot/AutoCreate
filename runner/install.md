# 내 PC에서 켜기

AutoCreate가 네이버 블로그·티스토리에 글을 올리려면 **내 PC의 브라우저**가 필요해요.
두 채널은 글쓰기 API가 없어서(네이버는 없고, 티스토리는 2024년 2월에 닫혔어요) 사람이 하듯 창을 열어 올립니다.

이 프로그램이 하는 일은 하나예요 — **앱이 만들어 둔 글을, 예약한 시각에, 내 계정으로 올린다.**

---

## 준비물

- Windows 10 이상 (Mac·Linux도 됩니다 — 아래 «다른 운영체제» 참고)
- **Node.js 20 이상** — 없으면 [nodejs.org](https://nodejs.org)에서 LTS 버전을 받아 설치해 주세요
- 앱에서 받은 **토큰** (`acr_`로 시작하는 글자. 앱 → 설정 → 러너 → «내 PC에서 켜기»)
- (영상까지 만들 때만) **ffmpeg** — 글만 올린다면 **없어도 됩니다.** 아래 «영상을 만들려면»을 봐 주세요

> 토큰은 **한 번만** 보여 드려요. 창을 닫으면 다시 볼 수 없으니, 못 받았으면 기기를 지우고 다시 등록해 주세요.

---

## 켜는 법 (Windows)

1. 받은 폴더에서 **`run.bat`을 두 번 클릭**하세요.
2. 처음 한 번은 준비에 몇 분 걸려요(브라우저를 내려받습니다).
3. 토큰을 물어보면 붙여넣고 Enter.
4. «Running. Keep this window open.»이 보이면 끝났어요. **이 창을 닫지 마세요.**

컴퓨터를 켤 때 자동으로 실행하려면: `Win + R` → `shell:startup` → 열린 폴더에 `run.bat` **바로가기**를 넣어 주세요.

---

## 확인해 보기

| 하고 싶은 것 | 명령 |
|---|---|
| 대기 중인 일이 있나 보기 | `node ac-runner.mjs --peek` |
| 한 건만 처리해 보기 | `node ac-runner.mjs --once` |
| 창을 띄워 눈으로 보기 | `node ac-runner.mjs --once --headed` |
| **올리지 않고** 임시저장까지만 | `node ac-runner.mjs --once --headed --dry-run` |
| 단계별 사진 남기기 | `RUNNER_SHOTS=1` (Windows: `set RUNNER_SHOTS=1`) → `runner/_shots/` |

> `--dry-run`은 글을 **올리지 않아요**. 임시저장까지만 하고 그 일감을 다시 대기열로 돌려놓습니다.
> 셀렉터가 살아 있는지 보고 싶을 때 안전하게 쓰세요.

---

## 계정 로그인이 필요하다고 나오면

네이버·티스토리가 «자동입력 방지(캡차)»나 «처음 보는 기기»를 물을 때가 있어요.
그럴 땐 앱이 «다시 로그인이 필요해요»라고 알려 드립니다.

1. 앱 → 계정 → 해당 계정의 **«다시 로그인»**
2. 이 프로그램이 **창을 띄웁니다** — 거기서 직접 로그인해 주세요(캡차도 직접 풀어 주세요)
3. 로그인이 끝나면 자동으로 저장돼요. 다음부터는 로그인 단계를 건너뜁니다.

**창에서 로그인할 때 이것만 꼭 해 주세요**(실측 2026-09-14)

| 채널 | 해야 할 것 | 안 하면 |
|---|---|---|
| 네이버 | **«로그인 상태 유지»를 켠다** | 창을 닫는 순간 세션이 만료돼 다음에 또 로그인해야 해요 |
| 티스토리(카카오) | 카카오톡으로 온 «로그인 확인»을 누르고, **«이 브라우저에서 2단계 인증 사용 안 함»을 켠다** | 글을 올릴 때마다 2단계 인증에서 멈춰요(자동 발행이 안 돼요) |

> 2단계 인증을 끄는 게 아니라 **이 컴퓨터만** 예외로 두는 설정이에요. 다른 기기에서는 그대로 2단계 인증이 걸립니다.
> 켜고 끄는 건 계정 주인이 정할 일이라 저희가 대신 누르지 않아요 — 창에서 직접 눌러 주세요.

> 비밀번호는 우리 서버에 **암호화해서** 보관하고, 이 프로그램이 일을 받을 때만 잠깐 내려받아 씁니다.
> 화면·기록에는 남기지 않아요.

## 영상을 만들려면 — ffmpeg

글(네이버·티스토리)만 올릴 거면 **이 절은 건너뛰어도 됩니다.**

쇼츠 같은 **영상**을 만들 때만 `ffmpeg`라는 무료 프로그램이 하나 더 필요해요.
영상 조각을 이어 붙이고 자막을 얹는 일을 합니다.

> 영상 만들기는 **다음 업데이트**에 들어가요. 지금 미리 깔아 두시면 그때 바로 쓸 수 있습니다.

### 설치

**Windows** — `winget`이 있으면 한 줄로 끝나요.
```
winget install Gyan.FFmpeg
```
직접 받으려면: [ffmpeg.org](https://ffmpeg.org/download.html) → «Windows» → 빌드를 받아 압축을 풀고,
그 안 `bin\ffmpeg.exe`의 **전체 경로**를 적어 두세요 (예: `C:\ffmpeg\bin\ffmpeg.exe`).

**Mac**
```bash
brew install ffmpeg
```

**Linux (우분투·데비안)**
```bash
sudo apt install ffmpeg
```

### 잘 깔렸는지 보기

```
ffmpeg -version
```
첫 줄에 `ffmpeg version ...`이 보이면 된 거예요.

### 경로 알려 주기 (`FFMPEG_PATH`)

보통은 **설치만 하면 알아서 찾습니다.** 아래 두 경우에만 경로를 직접 알려 주세요.

- «ffmpeg를 찾지 못했어요»가 뜰 때
- 압축만 풀어서 썼을 때(설치 프로그램을 쓰지 않으면 컴퓨터가 위치를 모릅니다)

`runner` 폴더에 `.env` 파일을 만들고 **한 줄**만 넣으면 돼요.

```
FFMPEG_PATH=C:\ffmpeg\bin\ffmpeg.exe
```

Mac·Linux는 이런 모양이에요.
```
FFMPEG_PATH=/opt/homebrew/bin/ffmpeg
```

경로를 넣었으면 그 경로로 확인해 보세요.
```
"C:\ffmpeg\bin\ffmpeg.exe" -version
```

> 경로에 **띄어쓰기**가 있으면(`C:\Program Files\...`) 따옴표로 감싸 주세요.
> `.env` 파일 안에서는 따옴표 없이 그대로 적으시면 됩니다.

### 자막 글꼴 (선택)

영상 자막은 **Pretendard**로 그립니다. 없어도 영상은 정상으로 만들어져요 —
Windows는 맑은 고딕, Mac은 애플 SD 산돌고딕으로 대신 그립니다(글자가 사라지지 않아요).

글꼴을 그대로 쓰고 싶으시면 [Pretendard 내려받기](https://github.com/orioncactus/pretendard/releases)에서
받아 설치해 주세요(Windows: 파일 우클릭 → «모든 사용자용으로 설치»).

> 글꼴을 바꾸면 자막 줄바꿈 위치가 조금 달라질 수 있어요. 이미 만든 영상은 그대로입니다.

## 꺼져 있으면 어떻게 되나요

**아무것도 사라지지 않아요.** 기다렸다가, 켜면 이어서 합니다. 취소되는 일은 없어요.

| 무엇 | 이 프로그램이 꺼져 있으면 |
|---|---|
| 네이버 블로그·티스토리 글 | **기다립니다.** 켜면 그때 올라가요 |
| 영상 만들기 | **기다립니다.** 켜면 그때부터 만들어요 |
| 블로거·워드프레스 글 | 그냥 나가요(이 프로그램이 필요 없어요) |
| 유튜브 쇼츠·릴스·스레드 | 그냥 나가요(이 프로그램이 필요 없어요) |

왜 두 갈래냐면 — 네이버와 티스토리는 **글쓰기 API가 없어서** 사람이 하듯 창을 열어 올려야 하고,
나머지 채널은 API가 있어서 서버가 바로 올릴 수 있어요. 영상 만들기는 계산이 무거워서 내 PC에서 합니다.

**30분 넘게 꺼져 있으면** 앱 홈 «해야 할 일»에 «내 PC 프로그램을 켜 주세요»가 뜹니다.
기다리던 일감은 **그대로 남아 있어요** — 켜면 바로 이어서 합니다.

> 영상은 ffmpeg도 있어야 해요. 없으면 이 프로그램은 **영상 일감을 아예 가져가지 않아요** —
> 가져가 놓고 실패하면 그 영상이 계속 재시도만 하다 막히거든요. 대신 앱에 «ffmpeg 없음»으로 표시돼요.
> 글 올리기는 ffmpeg 없이도 잘 됩니다.

## 자주 묻는 것

**창을 닫아도 되나요?**
닫아도 **글이 사라지지는 않아요** — 기다렸다가 켜면 올라갑니다. 다만 그동안은 안 나가요.
자세한 건 위 «꺼져 있으면 어떻게 되나요»를 봐 주세요.

**여러 계정을 쓰는데 섞이지 않나요?**
계정마다 **따로 된 브라우저 프로필**(`runner/profiles/`)을 쓰고, 글 하나마다 창을 새로 엽니다. 섞이지 않아요.

**컴퓨터가 느려지나요?**
글을 올리는 몇 분 동안만 브라우저가 뜹니다(보이지 않게). 평소에는 60초에 한 번 서버에 «할 일 있나요»만 물어봐요.

**다른 운영체제(Mac·Linux)**
```bash
cd runner
npm install
npx playwright install chromium
node ac-runner.mjs --token acr_...   # 처음 한 번
node ac-runner.mjs                    # 계속 돌기
```

**기기를 바꿨어요**
앱에서 예전 기기를 지우고 새로 등록해 주세요. 토큰은 기기마다 다릅니다.

## 잘 안 될 때

| 화면에 나온 말 | 뜻과 할 일 |
|---|---|
| `러너 토큰이 올바르지 않아요` | 토큰이 지워졌거나 기기가 삭제됐어요. 앱에서 다시 등록해 주세요. |
| `브라우저 도구(playwright)가 설치되지 않았어요` | `npm install` → `npx playwright install chromium` |
| `서버에 연결하지 못했어요` | 인터넷을 확인해 주세요. 계속되면 잠시 뒤 자동으로 다시 시도합니다. |
| `글쓰기 화면을 찾지 못했어요` | 채널이 화면을 바꿨을 수 있어요. **우리가 고칠 부분**이라 담당이 확인합니다(앱에도 같은 사유가 남아요). |
| `자동입력 방지(캡차)가 떴어요` | 위 «계정 로그인이 필요하다고 나오면» 대로 한 번만 직접 로그인해 주세요. |
| `ffmpeg를 찾지 못했어요` | 영상을 만들 때만 나오는 말이에요. 위 «영상을 만들려면»대로 설치하고, 그래도 나오면 `.env`에 `FFMPEG_PATH`로 전체 경로를 넣어 주세요. |

문제가 계속되면 앱 → 설정 → 문의하기로 알려 주세요. **`runner/_shots/` 폴더의 사진**을 함께 보내 주시면 훨씬 빨리 찾습니다.
